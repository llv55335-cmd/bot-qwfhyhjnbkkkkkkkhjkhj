# ==================================================================
# 平台特殊说明
# ==================================================================

# Windows 用户：
#   - uvicorn[standard] 在 Windows 装不上 uvloop，会自动跳过，不影响功能
#   - sentence-transformers 首次启动会下载约 500MB 模型到 ~/.cache/huggingface/

# VPS / Docker 部署：
#   - 内存建议 ≥ 2GB（sentence-transformers 加载后约占 500MB）
#   - Python base image 建议用 python:3.11-slim
#   - 如果不打算用向量检索（先只跑 HTTP 工具部分），可以注释掉
#     sentence-transformers 和 sqlite-vec 两行，启动会快很多

# 国内镜像加速：
#   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 如果 sentence-transformers 模型下载慢，配 hf 镜像：
#   export HF_ENDPOINT=https://hf-mirror.com
